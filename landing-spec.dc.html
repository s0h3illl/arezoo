Arezoo — Landing Page

Marketing page for the Arezoo wishlist app. Persian, RTL, mobile-first, responsive to desktop. Live design: Landing.dc.html

1 · Global setup

  • Root: <html dir="rtl" lang="fa">. All numerals are Persian (fa-IR digits).
  • Font: Vazirmatn (Google Fonts), weights 400 / 500 / 700 / 800 / 900. Fallback system-ui, sans-serif.
  • Page background #f8fafc (slate-50). Content container max-width: 1040px, horizontal gutter clamp(16px, 4vw, 32px).
  • Tailwind config: extend nothing — palette maps 1:1 to stock emerald + slate.

3 · Page structure

Single column, top to bottom: Header → Hero → Features (#features) → How it works (#how) → FAQ (#faq) → CTA band → Footer. Header nav anchors scroll to section ids.

4 · Sections

4.1 Header

  • Flex row, space-between, padding 20px vertical. Logo = 36px emerald tile (rounded-[12px]) with white «آ» + wordmark «آرزو» 22px/900.
  • Nav: text links «امکانات» → #features, «سوالات» → #faq (14px/500, slate-600); primary button «ورود» → /login.
  • Not sticky. On mobile the row stays single-line (links shrink, no hamburger).

4.2 Hero

  • Centered, max-width 760px, padding-block clamp(40px,8vw,88px). Background: radial emerald wash radial-gradient(ellipse 70% 60% at 50% 0%, #d1fae5, transparent 70%).
  • Badge pill: emerald-50 bg, emerald-200 border, emerald-700 text, 8px emerald dot — «برای دوست‌ها و خانواده».
  • H1 «آرزوهات رو بنویس،<br>بقیه‌ش با ماست» — clamp(30px, 6.5vw, 52px), weight 900, line-height 1.35.
  • Subcopy 15–18px, slate-600, line-height 1.9, max-width 520px.
  • CTA row (flex, wrap, gap 12): primary «ساخت اولین لیست» → /u/:username; secondary white/bordered «چطور کار می‌کنه؟» → #how (hover: emerald-200 border, emerald-700 text).

4.3 Features

  • Kicker «امکانات» (13px/800, emerald-500) + H2 «هدیه دادن، بدون حدس زدن» centered.
  • Grid: repeat(auto-fit, minmax(230px, 1fr)), gap 16 → 1 col mobile, 2 col tablet, 4 col desktop.
  • Card: white, slate-200 border, rounded-[20px], padding 24. Anatomy: 44px emerald-50 icon tile with 22px lucide icon stroked #059669 → title 17px/800 → body 14px slate-500 lh 1.9.
  • Icons (lucide): plus, share-2, gift, sparkle/diamond. Copy: ساخت لیست در چند ثانیه / اشتراک با یک لینک / رزرو مخفیانه‌ی هدیه / برای هر مناسبتی.

4.4 How it works

  • Full-width white band with 1px slate-200 top+bottom borders (only section on white).
  • 3 steps, grid auto-fit minmax(220px,1fr), centered text: 52px emerald circle with Persian numeral (۱ ۲ ۳, 22px/900 white) → title 17px/800 → body 14px slate-500.
  • Steps: لیستت رو بساز / آرزوهات رو اضافه کن / لینک رو بفرست.

4.5 FAQ

  • Max-width 720px. Native <details>/<summary> accordion — no JS. Hide default marker (list-style:none + ::-webkit-details-marker).
  • Item: white, slate-200 border, rounded-2xl, padding 18×22. Summary: 16px/700 question + trailing emerald «＋». Answer: 14px slate-500, 12px top margin.
  • First item open by default (config flag faqFirstOpen). 5 questions: pricing, no-signup viewing, reservation secrecy, privacy, supported stores.

4.6 CTA band (optional, flag showCtaBand)

  • Emerald-500 card, rounded-[28px], centered. H2 white 22–32px/900 «آماده‌ای اولین لیستت رو بسازی؟», subline emerald-100, white button «شروع رایگان» (emerald-700 text, hover emerald-50 bg).

4.7 Footer

  • White, slate-200 top border. Flex wrap, space-between: mini logo + wordmark · tagline (13px slate-400) · link «نمونه صفحه کاربر ←».

5 · Responsive & a11y

  • No breakpoint-specific layouts — fluid via clamp() type/spacing and auto-fit grids. Test at 360, 768, 1280px.
  • All interactive targets ≥ 44px on touch. Anchor links must not use scrollIntoView-based JS; native anchors suffice.
  • RTL: order comes free from dir="rtl"; keep logical (start/end) properties in CSS, no hardcoded left/right.
